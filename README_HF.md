# Constructor Equipos Pogo 2027

App Streamlit para construir equipos PvP de Pokemon GO con:

- Rankings Great/Ultra/Master regenerables
- Bitacora de cambios de movimientos (BitacoraCambios)
- Simulador battle_engine.py

Desplegada desde GitHub.

Para correr local:
```
pip install -r requirements.txt
streamlit run app.py
```
